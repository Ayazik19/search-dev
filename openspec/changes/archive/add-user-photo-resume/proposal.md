# Proposal: Добавление фото профиля

## Зачем это нужно
В текущем приложении `SearchDev` пользователь не может добавить аватар к резюме на этапе создания или редактирования. Сейчас в итоговом резюме используется только дефолтная иконка.

Это ухудшает восприятие резюме и снижает доверие к профилю.

## Что предлагается
### 1. Фронтенд (`React` + `Redux`)
- Добавить компонент загрузки фото с поддержкой `drag & drop` и выбора по клику.
- Добавить поле загрузки фото в форму создания и редактирования резюме.
- Расширить Redux state резюме полями `photoUrl` и `photoFile`.
- Добавить фронтенд-валидацию: только `JPEG` и `PNG`, размер не больше `5 MB`.
- Показывать превью фото, индикатор загрузки и понятные сообщения об ошибках.

### 2. Хранение данных
- Данные резюме сохраняются в `Firestore`.
- В документе резюме хранится только `photoUrl` — ссылка на загруженное фото.
- Сам `photoFile` хранится только на клиенте до момента загрузки и не сохраняется в `Firestore`.
- Итоговый экран использует сохранённый `photoUrl` для отображения аватара без перезагрузки страницы.

## Критерии приемки
- [ ] Пользователь может загрузить фото при создании и редактировании резюме.
- [ ] Фото отображается как аватар без перезагрузки страницы.
- [ ] Фото сохраняется в Redux state вместе с другими данными резюме.
- [ ] Валидация работает на фронтенде по типу и размеру файла.
- [ ] При ошибке показывается понятное сообщение пользователю.
- [ ] Данные резюме и ссылка на фото сохраняются в `Firestore`.
- [ ] Если фото не загружено, используется дефолтная иконка.
- [ ] `resumeFile` в этом изменении не используется.
