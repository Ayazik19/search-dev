# Design: Добавление фото профиля 

## Цель
Добавить загрузку фото пользователя на этапе создания и редактирования резюме, чтобы аватар отображался сразу в интерфейсе и сохранялся вместе с данными резюме.

## Что меняется
- Форма создания и редактирования резюме
- Итоговая страница готового резюме
- Redux state для хранения данных фото
- Валидация файла на фронтенде
- Сохранение данных резюме и ссылки на фото в `Firestore`

## Пользовательский сценарий
1. Пользователь открывает форму создания или редактирования резюме.
2. Выбирает фото через клик или drag & drop.
3. При ошибке получает понятное сообщение.
4. После сохранения фото отображается в итоговом резюме без перезагрузки страницы.

## UX-решения
- Зона загрузки поддерживает клик и drag & drop.
- После выбора файла показывается превью изображения.
- Во время загрузки отображается индикатор состояния.
- Ошибки валидации показываются рядом с полем загрузки.
- Если фото не загружено, используется дефолтная иконка.

## Правила валидации
- Фото: только `JPEG` и `PNG`.
- Максимальный размер файла: `5 MB`.
- Невалидный файл не попадает в состояние и не отправляется дальше.

## Изменения в состоянии приложения
В Redux state резюме добавляются поля:
- `photoUrl` — ссылка на загруженное фото
- `photoFile` — выбранный файл фото, используемый только на клиенте до загрузки

Состояние должно обновляться без перезагрузки страницы, чтобы форма и итоговый экран использовали одни и те же данные.

## Поведение на бэкенде
- Данные резюме сохраняются в `Firestore`.
- В документе резюме хранится только `photoUrl`.
- Сам файл фото не сохраняется в `Firestore`.
- Клиент получает URL, который можно сразу показать в интерфейсе.

## Риски и ограничения
- Большие изображения могут замедлять загрузку, поэтому лимит размера должен соблюдаться строго.
- Нужно синхронизировать локальный Redux state и данные, полученные после загрузки на сервер.
- Ошибки загрузки не должны сбрасывать уже введённые данные формы.

## Критерии завершения
- Фото можно загрузить и увидеть в превью.
- Фото отображается как аватар без обновления страницы.
- Фото сохраняется в state.
- Валидация отсекает неподходящие файлы.
- Ссылка на загруженное фото сохраняется в БД.
