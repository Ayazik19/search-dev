# Tests: Добавление фото профиля и резюме пользователя

## 1. Загрузка фото через клик
- **Given** пользователь открыл форму создания или редактирования резюме
- **When** он выбирает валидный файл `JPEG` или `PNG` через клик по зоне загрузки
- **Then** файл принимается, показывается превью изображения, а в состоянии появляется `photoFile`

## 2. Загрузка фото через drag & drop
- **Given** пользователь открыл форму создания или редактирования резюме
- **When** он перетаскивает валидный файл `JPEG` или `PNG` в зону загрузки
- **Then** файл принимается, показывается превью изображения, а в состоянии появляется `photoFile`

## 3. Валидация формата файла
- **Given** пользователь пытается загрузить файл, который не является `JPEG` или `PNG`
- **When** файл попадает в зону загрузки
- **Then** файл не добавляется в состояние, а рядом с полем показывается сообщение об ошибке

## 4. Валидация размера файла
- **Given** пользователь пытается загрузить файл больше `5 MB`
- **When** файл попадает в зону загрузки
- **Then** файл не принимается, в state ничего не сохраняется, и показывается ошибка валидации

## 5. Отображение индикатора загрузки
- **Given** пользователь выбрал валидное фото
- **When** фото загружается на бэкенд или в облачное хранилище
- **Then** отображается индикатор загрузки, а форма не сбрасывает уже введённые данные

## 6. Сохранение URL фото в state
- **Given** загрузка фото завершилась успешно
- **When** клиент получает URL от бэкенда
- **Then** в Redux state обновляется `photoUrl`, и этот URL доступен для формы и итогового экрана без перезагрузки

## 7. Отображение аватара в итоговом резюме
- **Given** у резюме есть `photoUrl`
- **When** пользователь открывает итоговую страницу резюме
- **Then** отображается загруженное фото, а не дефолтная иконка

## 8. Дефолтная иконка без фото
- **Given** фото не загружено
- **When** пользователь открывает форму или итоговую страницу резюме
- **Then** отображается дефолтная иконка вместо аватара

## 9. Сохранение фото на бэкенде
- **Given** пользователь сохранил резюме с фото
- **When** данные уходят на бэкенд
- **Then** ссылка на файл сохраняется в БД вместе с данными резюме

## 10. Ошибка загрузки фото
- **Given** пользователь выбрал валидное фото
- **When** загрузка на бэкенд завершается с ошибкой
- **Then** ошибка показывается пользователю, а остальные данные формы остаются на месте
