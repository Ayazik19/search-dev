# Proposal: Resume Completion Modal

## Название изменения
**resume-finish-details**

## Проблема
После завершения последнего шага резюме не хватает небольшого блока, который мягко подсказывает пользователю, какие данные ещё нужно добавить, чтобы резюме стало полноценным.

## Решение
Показать модальное окно сразу после сабмита последнего шага. Оно должно:
- сообщать, что до завершения осталось совсем немного;
- показать главный заголовок и короткое пояснение;
- предложить заполнить недостающие поля резюме;
- использовать короткие, понятные лейблы и опции для каждого поля.

## Поля формы
- `#sym:statusSearchResume` — статус поиска работы
- `#sym:busyness` — тип занятости
- `#sym:workFormat` — формат работы
- `#sym:salary` — ожидаемая зарплата

## Содержимое модалки
- **Intro:** Just a few details left
- **Headline:** Let’s finalize your resume
- **Subtitle:** You’ve filled most of your resume. Add the missing details below to finish it.

## Ожидаемый результат
Пользователь видит понятный финальный шаг и может быстро заполнить недостающие данные без ощущения отдельного сложного процесса.
