# Добавление фото профиля в резюме

## Что должно работать
- Пользователь может добавить фото при создании и редактировании резюме.
- Фото можно выбрать по клику.
- После выбора показывается превью изображения.
- Фото отображается в итоговом резюме как аватар без перезагрузки страницы.
- Если фото не загружено, используется дефолтная иконка.

## Правила загрузки
- Разрешены только файлы `JPEG` и `PNG`.
- Максимальный размер файла — `5 MB`.
- Невалидный файл не попадает в состояние и не отправляется на сохранение.
- Ошибка валидации показывается рядом с полем загрузки.

## Состояние приложения
В Redux state резюме хранятся:
- `photoUrl` — ссылка на загруженное фото
- `photoFile` — выбранный файл, который используется только на клиенте до загрузки

Состояние должно обновляться без перезагрузки страницы, чтобы форма и итоговый экран использовали одни и те же данные.

## Сохранение данных
- Данные резюме сохраняются в `Firestore`.
- В документе резюме хранится только `photoUrl`.
- При успешной загрузке клиент получает URL и сразу использует его для отображения аватара.
- При ошибке сохранения уже введённые данные формы не сбрасываются.

## Поведение интерфейса
- Зона загрузки поддерживает клик и `drag & drop`.
- После выбора файла показывается превью.
- В момент загрузки можно показывать индикатор состояния.
- При клике на превью фото может открываться полноэкранный просмотр.
- В полноэкранном просмотре доступны действия: заменить фото, скачать фото, удалить фото.
- Закрытие полноэкранного просмотра должно быть доступно без потери данных формы.

## Критерии приёмки
- Фото можно загрузить через клик и через `drag & drop`.
- Фото проходит фронтенд-валидацию по типу и размеру.
- Фото отображается в форме и в итоговом резюме.
- В `Firestore` сохраняется ссылка на фото, а не сам файл.
- Ошибки валидации и сохранения не ломают сценарий создания резюме.
- Если фото не загружено, отображается дефолтная иконка.
- Изменения работают без перезагрузки страницы.
