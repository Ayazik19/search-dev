# Поиск существующих резюме на главной странице

## Как работает
- На главной странице есть поле ввода для поиска резюме.
- Соискатель может найти резюме по названию и списку навыков.
- После поиска показывается список найденных резюме.
- Также выводится текст с количеством найденных результатов и запросом пользователя.
- Если совпадений нет, отображается только пустое состояние без списка результатов.

## Правила
Исключительно поиск по названию резюме, списку навыков

## Где хранится
- Данные для поиска хранятся в `Firestore` в коллекции `resumes`.
- Для поиска используются поля `nameResume` и `skills`.
- На фронтенде найденные резюме временно сохраняются в состоянии компонента через `useState`.
- При отсутствии совпадений список результатов не отображается.
